# ADR-0015：财务期间与时点（PIT）

- **状态：** accepted（2026-11-06，项目负责人按评审稿建议通过）
- **日期：** 2026-11-06
- **评审人 / 批准人：** 项目负责人
- **规格书出处：** 第 12.5 节、17.0 节（章节映射见 [../README.md](../README.md)）

## 背景

`period_end` 不等于市场能获得数据的时间。回测或历史研究若使用事后才公开的数据或修订值，会产生前视偏差。

## 候选方案

| 方案 | 说明 | 结论 |
|---|---|---|
| A 以 `period_end` 作为可用时间 |  | 放弃：会读到尚未公开的数据 |
| B 以披露时间为准 | SEC 取 `acceptanceDateTime`；仅有日期时视为下一交易日开盘可用，并标 `pit_precision = 'date'` | **采纳** |
| C 以入库时间为准 |  | 放弃：与真实公开时间无关 |

## 决定（规格书推荐）

`published_at` 取 filing 的 `acceptanceDateTime`；仅有日期则保守取下一交易日开盘；修订以新版本追加，`supersedes_id` 指向旧版本；TTM 必须由连续 4 个可验证季度构成，缺季度则不可用。

## 理由

- 避免前视偏差；
- 保留重述历史，使“当时知道什么”可复原。

## 后果

- 需要交易日历（Phase 2 的 `market_calendars`）；
- YTD 相减推导单季度需记录推导来源。

## 测试影响

- 研究时点之前读不到之后公开的数据；
- 重述后新旧版本并存；
- 日期精度事实按下一交易日可用；
- 缺季度时 `TTM_PERIOD_INCOMPLETE`。

## 评审结论（2026-11-06）

- **盘后提交何时可用：** `published_at` 始终记录 `acceptanceDateTime` 原值。对依赖价格的计算：受理时间在美东 09:30 之前（盘前）的事实自当日开盘起可用；09:30 及之后（盘中、盘后、非交易日）的事实自下一交易日开盘起可用。盘中受理按下一交易日处理是有意的保守选择。
- **交易日历来源：** 使用锁定版本的 `exchange_calendars`（XNYS），结果写入 `market_calendars`；每年对照 NYSE 公布的休市安排核对一次。
