# ADR-0007：SBC 处理政策

- **状态：** accepted（2026-11-06，项目负责人按评审稿建议通过）
- **日期：** 2026-11-06
- **评审人 / 批准人：** 项目负责人
- **规格书出处：** 第 18.1.2 节（章节映射见 [../README.md](../README.md)）

## 背景

股权激励（SBC）既是真实经济成本，也常在现金流量表中被加回。处理不一致会让 FCFF 被系统性高估，或被重复扣减。

## 候选方案

| 方案 | 说明 | 结论 |
|---|---|---|
| A 加回 SBC | 沿用多数卖方研究做法 | 放弃：把真实成本当作非现金项，高估自由现金流 |
| B 不加回 | SBC 视为经济成本；NOPAT 基于包含 SBC 的 EBIT | **采纳** |
| C 加回并按未来稀释折价 | 需要稀释预测模型 | 放弃：MVP-1 无稀释预测 |

## 决定（规格书推荐）

FCFF 默认不加回 SBC；若以 CFO 为起点，必须识别并扣回已被加回的 `sbc_expense`；禁止在没有明确模型依据时对同一笔 SBC 同时扣成本又折稀释。

## 理由

- 口径单一、可解释；
- 避免重复加回或重复扣减。

## 后果

- 对高 SBC 公司估值更保守，可能与市场共识偏离；
- MVP-1 使用 12.6 的稀释股数代理口径；
- 未来引入稀释预测须新 ADR 取代本条（`superseded`）。

## 测试影响

- 以 EBIT 为起点与以 CFO 为起点的两条路径，对同一 fixture 结果一致（32 节必测）。

## 评审结论（2026-11-06）

- **`sbc_expense` 覆盖率不足怎么办：** MVP-1 的 DCF 以 EBIT 为起点，EBIT 已包含 SBC 费用，不依赖 `sbc_expense`。`sbc_expense` 只用于以 CFO 为起点的交叉校验和 SBC / Revenue 指标，缺失时跳过交叉校验并在报告中注明，不阻断估值。覆盖率仍在 Spike S1 中统计。
- **是否展示“加回 SBC”的对照值：** MVP-1 不展示，避免读者把对照值当作第二个估值结论；以后如需要另立 ADR。
