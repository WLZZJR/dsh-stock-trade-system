# ADR-0004：MVP 市场范围与三档交付

- **状态：** accepted（2026-11-06，项目负责人按评审稿建议通过）
- **日期：** 2026-11-06
- **评审人 / 批准人：** 项目负责人
- **规格书出处：** 第 0.3 节（章节映射见 [../README.md](../README.md)）

## 背景

项目目标是全球市场，但数据覆盖、许可与财务口径在不同市场差异很大；Agent 与 MCP 依赖一个已验证的确定性内核。

## 候选方案

| 方案 | 说明 | 结论 |
|---|---|---|
| A 全球一次到位 |  | 放弃：范围过大，数据与许可无法同时验证 |
| B 美股纵向切片 + 三档交付 | MVP-1 美股确定性产品（零 LLM）→ MVP-2 Agent + MCP → MVP-3 Harness | **采纳** |
| C 美股 + 港股 |  | 放弃：需要另一套 Provider 与财务适配 |

## 决定（规格书推荐）

MVP-1 只做美国普通股（NYSE / NASDAQ / NYSE American），无 LLM、MCP、Harness 依赖；数据模型保持全球化；ADR、外国私人发行人、ETF 等明确不纳入；每档只验收本档范围。

## 理由

- 先建立可复算、可追溯的内核，再叠加智能体；
- MVP-1 可独立部署、独立验收。

## 后果

- 全球化数据模型会带来一定的前期复杂度；
- MVP-1 内部再分 M1-a（数据层 + 财务引擎）与 M1-b（估值 + Web + 部署）两个检查点。

## 测试影响

- LLM Independence 测试：关闭所有 LLM 配置后 MVP-1 全部 E2E 通过；
- MVP-1 默认启动集不含 `mcp`。

## 评审结论（2026-11-06）

- **M1-a 是否作为对外演示里程碑：** 否。M1-a 是内部检查点（尚无 Web），以 API 与测试报告作为证据。
- **非美国市场的启动条件：** MVP-1 验收通过 + 该市场 Provider 完成许可审查 + 该市场独立验收后才标记正式支持（见 RISKS）；每个新市场单独立 ADR。
