# ADR-0016：证券主键与标识符

- **状态：** accepted（2026-11-06，项目负责人按评审稿建议通过）
- **日期：** 2026-11-06
- **评审人 / 批准人：** 项目负责人
- **规格书出处：** 第 10 节、16 节（章节映射见 [../README.md](../README.md)）

## 背景

ticker 会在不同交易所重复，也会随时间被复用；同一发行主体有多只证券与多个上市记录；外部标识符（ISIN、FIGI、CUSIP 等）带有效期。

## 候选方案

| 方案 | 说明 | 结论 |
|---|---|---|
| A ticker 作主键 |  | 放弃：不唯一、会复用 |
| B 分层 + UUID + 排他约束 | Issuer / Security / Listing / Identifier 分层，内部 UUID；`listings` 与 `identifiers` 用 GIST 排他约束防有效期重叠 | **采纳** |
| C 以 FIGI 作主键 |  | 放弃：OpenFIGI 不是完整无缺失的历史主数据库 |

## 决定（规格书推荐）

Issuer / Security / Listing 分离，内部使用 UUID；外部标识符为可变、带有效期的映射记录；`identifiers` 用 `btree_gist` 排他约束与实体存在性触发器；ticker 不得作为全局主键；不另设 `UNIQUE (venue_id, ticker, valid_from)`；主数据表带删除保护触发器。

## 理由

- 表达 ticker 复用、跨交易所、ADR 与本地股的区别；
- 数据库层面保证不重叠，而不是依赖应用代码。

## 后果

- `identifiers` 是多态表，无法用外键保证引用完整，依赖触发器，实体删除导致的孤儿风险由主数据表的删除保护触发器消除；
- `listings.valid_from` 默认值为 `CURRENT_DATE`，历史上市记录必须显式给出；
- 需要证券消歧服务，多候选时不得自行选择。

## 测试影响

- 同 ticker 不同场所不冲突；同场所有效期重叠被拒；
- 标识符有效期重叠被拒；指向不存在实体被拒；
- 区间首尾相接（`[)`）不冲突。

## 评审结论（2026-11-06）

- **`identifiers` 是否按实体类型拆表：** 不拆。保留多态表 + 实体存在性触发器，并新增反向保护：`issuers`、`securities`、`listings`、`venues` 加 `BEFORE DELETE` 触发器，被 `identifiers` 引用时拒绝删除，消除孤儿风险。
- **`UNIQUE (venue_id, ticker, valid_from)` 是否冗余：** 冗余，删除；排他约束已覆盖“同一天重复开始”的情况。
