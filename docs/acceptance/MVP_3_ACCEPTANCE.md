### 33.3 MVP-3 验收

- [ ] Harness 插件可连接已部署的 MCP 服务，并调用核心工具。
- [ ] 插件不复制核心研究逻辑；工具参数和结果映射与 MCP 契约一致。
- [ ] Run 的创建、状态、取消和结果展示正常；长任务不阻塞 Harness 对话。
- [ ] Harness 插件版本与目标 Harness 版本有兼容性记录。
- [ ] Harness 不可用或升级时，独立平台和研究服务不受影响。
